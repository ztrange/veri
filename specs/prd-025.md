# PRD 025 requirements: the repository says what it is now, and carries nothing nobody runs

The format is `specs/utility-skills.md`'s: each row makes one claim a reviewer, a grader or a test
can mark true or false; IDs are stable, and a dropped row leaves a gap.

**Status: DRAFT, from the 2026-11-10 code audit. 025.1 carries rows; 025.2–025.10 are outlines,
and four of them wait on a decision. No decision has been put to Mario yet. Nothing is filed.**

## The goal

A reader of the Makefile, the CI workflow, `CLAUDE.md` or `SKILL.md` is told what is true today.
A script, a module or a test that nothing uses is gone. A helper exists once.

No criterion fixes a number.

  cases). The audit counted 43 `test_skill_*` files (8,864 lines) and about 45,000 test lines
  that mention a prose file; that count is input for PRD 011, not a new sub-PRD.
- **Splitting `tests_frozen.py`.** PRD 017 owns the deep modules under the hot spots.
- **Test speed.** PRD 023. Sub-PRD 025.6 below overlaps 023.8 and is filed once, under whichever
  goes first.
