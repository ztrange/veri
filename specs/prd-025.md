# PRD 025 requirements: the repository says what it is now, and carries nothing nobody runs

The format is `specs/utility-skills.md`'s: each row makes one claim a reviewer, a grader or a test
can mark true or false; IDs are stable, and a dropped row leaves a gap.

**Status (2026-11-17): every sub-PRD, 025.1–025.20, is filed and closed (#4035–#4054), and the tracker #3611 is closed. Nothing is open. Facts were last re-checked on 2026-11-15 against `main` at `3b95202b60`; the dashboard and `projects/` left veri on 2026-11-11 (#3682) and PRD 014 is closed (#546); no row here named either, so no row was voided.**

## The goal

A reader of the Makefile, the CI workflow, `CLAUDE.md` or `SKILL.md` is told what is true today.
A script, a module or a test that nothing uses is gone. A helper exists once.

No criterion fixes a number.

## What this PRD does not hold

- **Tests that pin prose wording.** PRD 011 owns them (graded requirements replace substring
  cases). The audit counted 43 `test_skill_*` files (8,864 lines) and about 45,000 test lines
  that mention a prose file; that count is input for PRD 011, not a new sub-PRD.
- **Splitting `tests_frozen.py`.** PRD 017 owns the deep modules under the hot spots. 025.13
  removes the bash-suite cases of `test_tests_frozen_process.py` and splits nothing.
- **Test speed.** PRD 023. Shrinking the process twins is 023.8's (settled 2026-11-15); 025.6 keeps
  only what 023.8 does not cover.
