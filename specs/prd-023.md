### What the 2 s goal implies

Collection alone is about 49 s of CPU for 392 files. A 2 s full run is therefore not reachable by
tuning: it needs most cases to stop starting processes and the collection cost to fall by an
order of magnitude, or `make test` to mean "the cases this change can affect". Which of those is
intended is the first decision in *Open*.

## Measurements owed

Run with no conductor live:

- `VERI_PROFILE_THRESHOLD=0.5 make profile`, grouped by file, for the per-case and per-file cost
  and the cases that make the tail.
- A run with `--durations=0 --durations-min=0.05`, to see setup and teardown, which
  `make profile` leaves out.
- `python3 -m pytest skills/tdd/scripts/tests/py --collect-only -q -p no:cacheprovider`, twice
  with a fixed `PYTHONPYCACHEPREFIX`, for warm collection time.
- `python3 -X importtime -m pytest … --collect-only`, for the import share.
- `make test` with `--dist worksteal` against the default.
