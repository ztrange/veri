## 037.6 — a prompt with no rows is refused

Mario gets: a new file under `skills/tdd/scripts/prompts/` cannot land without rows. Depends on
037.2 to 037.5 (037.1 has landed), or the guard would fail on `main` the day it lands. (Old 037.7.)

Mechanism: `owed_listed()` (`grade_prose.py:265`) sees only units some `REQUIREMENTS.md` already
lists (`listed_pairs`), so a prompt file with no rows is invisible to it. The guard is a new scan
of `skills/tdd/scripts/prompts/` in `owed_listed` or in `prose_owed.main`, printing each file
(`REQUIREMENTS.md` excepted) that no tracked `REQUIREMENTS.md` lists, on a line of its own ending
` (no rows)`, like the ` (orphan)` lines, and making the script exit 1. A repository without that
directory adds nothing. `build_verify_prompt` is not involved. The guard is watched to fail (a
fragment added with no rows goes red) and restored, as the repository's testing idiom requires.
