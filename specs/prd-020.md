# PRD 020 requirements: operator rules live in veri, not in one machine's memory

The format is `specs/utility-skills.md`'s: each row makes one claim a reviewer, a grader or a test
can mark true or false; IDs are stable, and a dropped row leaves a gap.

**Status (2026-11-17): every sub-PRD is filed and closed: 020.1–020.13 are #4057–#4069 (020.0 moved to PRD 013.6, #4071). Nothing is open. Ungraded prompts stay deferred to a later PRD, not yet a spec.**

## The goal

A coordinator or dev session on another machine behaves like the one on the development Mac.
Today many operating rules learned from incidents live only in Claude's per-machine memory
directory (`~/.claude/projects/<veri>/memory/`). A session anywhere else never reads them and
repeats the incident. Each rule moves into the skill or principle that governs the behaviour.
When its sub-PRD merges, the memory file is deleted, so the repo is the only copy (J12).

## PRD 020.3: a merge that errored is never re-merged over a landed PR

landed before doing anything else, and never rebases a PR already on main.
**Depends on:** nothing. `queued-merge.sh` already behaves this way (SC51, SC52); this brings the
`vmerge` prose level with it.

| ID | Requirement | Why |
|---|---|---|
| R1 | `skills/vmerge/SKILL.md` *Steps* step 5 (*Read `state`*) says that after a merge call that errors, the PR's `state` is re-read over the settle window `queued-merge.sh` uses (`VERI_MERGE_SETTLE_READS` reads, `VERI_MERGE_SETTLE_SLEEP` s apart) before anything else, and a `MERGED` read is treated as success. | PR #3486 (2026-11-09): the merge returned `502 Bad Gateway` but landed. |
| R2 | The same step says no retry rebases or pushes a PR whose head is an ancestor of origin/main (`git merge-base --is-ancestor <head> origin/main`); such a PR is reported to the human, the lock released. | The #3486 retry force-pushed a head equal to a main commit; GitHub closed the PR as CLOSED, not MERGED, and #3479–#3481 never auto-closed. |
| R3 | `skills/vmerge/REQUIREMENTS.md` gains rows for R1–R2 and `skills/vmerge/GRADED` is regraded PASS. | Graded unit. |
