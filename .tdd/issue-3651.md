- [x] A 503 whose stderr reaches the GraphQL adapter (GraphQLAdapter._run) is retried like any other 5xx: a gh stub whose queue read fails once with exit 1 and stderr "HTTP 503: No server is currently available to service your request", then answers, leads dispatch run in-process with VERI_DISPATCH_RETRY_SLEEP=0 to read the queue and proceed instead of exiting 2 ⟦criterion 1⟧
- [x] A 503 whose stderr reaches the REST adapter (RestAdapter.issue_view) is retried like any other 5xx: a gh stub whose issue read through the REST adapter fails once with exit 1 and stderr "HTTP 503: No server is currently available to service your request", then answers, leads dispatch run in-process with VERI_DISPATCH_RETRY_SLEEP=0 to proceed instead of exiting 2 ⟦criterion 1⟧ ⟂ retired unpinnable
- [ ] A 5xx spell longer than the 3-try cap is ridden out: a gh stub whose queue read returns HTTP 503 for its first 4 calls and then answers leads dispatch run in-process with VERI_DISPATCH_RETRY_SLEEP=0 to proceed instead of exiting 2 ⟦criterion 2⟧
- [ ] Once the retry window is spent dispatch still exits 2 naming the HTTP status: a gh stub whose queue read always returns HTTP 503 ends dispatch run in-process with VERI_DISPATCH_RETRY_SLEEP=0 in exit 2 with 503 on stderr, with no real wait ⟦criterion 3⟧
