### stage_recorder copies no script: every script a stage does not replace is reached by a link to the script under test, never by cp ⟦criterion 1⟧
- `stage_recorder` and `stage_title_recorders` use two different ways to stop a recorder stub from being written through a link: the first skips linking `detach-leaf.sh` with a name test, the second runs `rm -f` before writing. They could share one approach (link everything, then `rm -f` before each stub). This is a consistency change rather than duplication removal, and the later step that writes each recorder stub once per suite run (criterion 2) will rewrite both functions anyway.
