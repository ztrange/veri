# Plan for #1632 — PRD 009: a source-judged guard keeps process starts, sleeps, sockets and nested suites out of the pytest fast tier

- [x] A planted test_*.py file whose own source starts a process through `subprocess` (e.g. `subprocess.run`) is reported by the fast-tier guard as an offence naming `<file>:<line>` of that call, judged by reading the file's source with no timing and no process started, while a clean planted test_*.py file (no process, sleep, socket or nested suite) yields no offence; pinned by small in-process pytest cases (no process mark) over files planted in tmp_path ⟦criterion 1⟧
- [ ] A planted test_*.py file that starts a process through a name imported from subprocess (`from subprocess import run` then `run(...)`) or through an aliased module (`import subprocess as sp` then `sp.run(...)`) is reported by the fast-tier guard as a process-start offence naming `<file>:<line>` of the call; pinned by small in-process pytest cases over files planted in tmp_path ⟦added⟧ ⟦criterion 1⟧
- [ ] A planted test_*.py file whose own source calls `os.system`, an `os.exec*` function (e.g. `os.execv`), an `os.spawn*` function (e.g. `os.spawnl`) or uses `pty` (e.g. `pty.spawn`) is each reported by the fast-tier guard as a process-start offence naming `<file>:<line>`; one planted offender per form, each turning the guard red, pinned by small in-process pytest cases over files planted in tmp_path ⟦criterion 1⟧
- [ ] A planted test_*.py file whose own source calls `time.sleep` is reported by the fast-tier guard as a sleep offence naming `<file>:<line>`; pinned by a small in-process pytest case over a file planted in tmp_path ⟦criterion 1⟧
- [ ] A planted test_*.py file whose own source opens a socket (e.g. `socket.socket(...)` or `socket.create_connection(...)`) is reported by the fast-tier guard as a socket offence naming `<file>:<line>`; pinned by a small in-process pytest case over a file planted in tmp_path ⟦criterion 1⟧
- [ ] A planted test_*.py file whose own source runs another suite — calls `pytest.main(...)`, or names another suite file (a `test_*.py` or `*.test.sh` path) as what it runs — is reported by the fast-tier guard as a nested-suite offence naming `<file>:<line>`; pinned by a small in-process pytest case over a file planted in tmp_path ⟦criterion 1⟧
- [ ] The fast-tier guard works against an exemption table in which every entry carries a reason: an offence whose `<file>:<line>` the table exempts is not reported, while the same offence absent from the table is, and a table entry with an empty reason is refused (the guard fails, naming that entry); pinned by small in-process pytest cases ⟦criterion 1⟧
- [ ] `make test` runs the fast-tier guard over every `test_*.py` under `skills/tdd/scripts/tests/py/unit/` with the real exemption table, and a run with an offending file there fails, naming `<file>:<line>`; the sweeping case carries `@pytest.mark.tree_audit(...)` and passes over the tree as committed ⟦criterion 1⟧
