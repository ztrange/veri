## Notes — what the port does where no case pins it

- A command not found: return 127, `timed-test-run.sh: <cmd>: command not found` on stderr. A command not executable: return 126, `timed-test-run.sh: <cmd>: Permission denied` on stderr. A signal death: nothing on stderr. Bash's own lines named `$0` and a pid, neither byte-reproducible, so no case pins these texts.
- A shell builtin or an exit-contract.sh function typed as the command (`exit 5`, `refuse`, `to_contract 9`, `cd /tmp`) is resolved on PATH like any word: one that is not on PATH returns 127 with the event written; `echo` runs the PATH `echo`. Every caller today types an external command.
- A Ctrl-C to the whole process group: unverified on main, and not pinned; `KeyboardInterrupt` escapes main, the shim exits 1, no line is written.
