Order: the two bash cases the issue asks for before the port (the exit-2 floor case with nothing on stdout or stderr, the symlink case) are written first, against the bash script; the one implementation case — `red-divergence.sh` in migration slice 6 — is cut next, in its own commit with its pytest replacement, which brings `veri/red_divergence.py` into being while `red-divergence.sh` is still bash; the module then grows one pinned behaviour at a time under `tests/py/test_red_divergence.py`, every case calling `veri.red_divergence.main(argv)` and faking only process boundaries (stdin as bytes, captured stdout and stderr, the environment, prompt files under `tmp_path`), never patching a function of `veri.red_divergence` or `veri.report`; the shim lands once every branch it exposes is pinned (#797); the bash cases the survival rule cuts go last.

Criterion 1 asks for the slice-6 cut "in its own commit before the port" and criterion 2 for the contract commit to "precede any cut"; both cannot hold, because slice 6's check greps the script for a `source …lib/exit-contract.sh` line a shim cannot carry. The slice-6 cut comes first, as criterion 1 states, and criterion 2's "any cut" is read as any cut of a `tests/unit/red-divergence.test.sh` case: the shim commit precedes every one of those.

Decisions the issue left to the plan:
- Bytes: the module reads `sys.stdin.buffer`, decodes it as UTF-8 with `surrogateescape`, and writes the reason through `sys.stdout.buffer` encoded the same way, so bytes in are bytes out under any locale.
- A write that raises (stdout closed or full) is left uncaught and ends with exit 1, as `cat` failing does today; no wrapper turns an exception into exit 2.
- Run through a symlink to the file, the shim keeps `exec python3 "$(dirname "$0")/veri/red_divergence.py"` as `status.sh` does: python3's own exit 2 and its own `can't open file` text, in place of bash's `command not found` lines and exit 2.
- The bash case at `:123-135` that runs the script on every verdict the prompts offer is kept as a survivor, so it is the case keeping the offered verdicts covered.
