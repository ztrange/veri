# Plan for #847 — veri/github.py reaches GitHub through one port with GraphQL, REST and fixture adapters, the GraphQL→REST fallback a composition of two of them

Refactor-kind run: each step is one named refactoring, and its criterion is the shell predicate it names — false before the step, true after it. `F` below is `skills/tdd/scripts/veri/github.py`. The module-level `_gh`, `_gh_graphql`, `_gh_api` helpers stay (wait_ci.py imports `_gh` and `_gh_api`), and every adapter still starts `gh` through them, so through `subprocess.run`.

- [ ] Extract Class `RestAdapter` for reads: the REST driver's read work moves out of the public functions into methods of one `class RestAdapter` — the `page=N` paging loop with `&page=` after an existing `?`, the empty-page pattern and `NoAnswer(answer)` carrying pages already read (from `gh_rest_list`), and the `gh api …/issues/<n>` call, its JSON decode line on stderr and its reshaping (`null` body → `"\n"`, labels one per line) (from `gh_issue_view`'s fallback branch) — and those public functions call the adapter instead, signatures and return values unchanged. Predicate: `grep -q '^class RestAdapter' F && ! awk '/^def gh_/,/^$/' F | grep -E 'json\.loads|page=' > /dev/null` ⟦criterion 1⟧
- [ ] Move Method: `gh_issue_edit`'s PATCH (`gh api -X PATCH …/issues/<n> -F body=@<file>`) and `gh_issue_create`'s POST (`gh api …/issues -f title=… -f body=… -q .html_url`) move into `RestAdapter` methods, and both public functions call the adapter, signatures, return values and `NoAnswer` raises unchanged. Predicate: `grep -q '^class RestAdapter' F && ! awk '/^def gh_/,/^$/' F | grep -E '_gh(_api)?\(' > /dev/null` ⟦criterion 1⟧
- [ ] Extract Class `GraphQLAdapter`: the `gh issue|pr …` calls with stderr dropped (`gh_list`'s `_gh_graphql(*args)` and `gh_issue_view`'s `issue view <n> --json <field> -q <query>`) move into methods of one `class GraphQLAdapter`, each raising `NoAnswer("")` on a non-zero exit, and `gh_list`/`gh_issue_view` call it, falling to `RestAdapter` on its `NoAnswer`. Predicate: `grep -q '^class GraphQLAdapter' F && ! awk '/^def gh_/,/^$/' F | grep -E '_gh_graphql|returncode' > /dev/null` ⟦criterion 1⟧
- [ ] Replace the two inline fallbacks with a composed `class FallbackAdapter(first, second)`: its list and issue view try `first` and on its `NoAnswer` ask `second`; its REST-only operations (paged REST list, issue edit, issue create) go to `second` directly with no GraphQL attempt; `gh_list` and `gh_issue_view` lose their inline try/fallback and delegate to it, and the adapter carries no copy of either driver's `gh` invocation, paging or REST-answer parsing. Predicate: `grep -q '^class FallbackAdapter' F && ! awk '/^def gh_/,/^$/' F | grep -E 'except|GraphQLAdapter' > /dev/null && ! awk '/^class FallbackAdapter/,/^class [^F]|^def /' F | grep -E '_gh|page=|json\.loads' > /dev/null` ⟦criterion 2⟧
- [ ] Extract Class `FixtureAdapter`: a `class FixtureAdapter`, given the fixture directory, answers `<directory>/<fixture>`'s contents and starts no process; `gh_json` reads the file through it instead of opening it itself, behaviour unchanged. Predicate: `grep -q '^class FixtureAdapter' F && ! awk '/^def gh_json/,/^$/' F | grep -E 'open\(' > /dev/null` ⟦criterion 1⟧
- [ ] Introduce one selection function `_select`: `_select` alone reads `VERI_GH_JSON`, at call time, and alone constructs adapters — the fixture adapter for `gh_json` when it is set, `FallbackAdapter(GraphQLAdapter(), RestAdapter())` otherwise, and the fallback adapter for every other operation whether or not it is set (so `gh_issue_view`/`gh_issue_edit` still run `gh` with it set); `gh_json` with no gh args still goes straight to REST. No public function reads the environment or constructs an adapter. Predicate: `grep -q '^def _select' F && ! awk '/^def gh_/,/^$/' F | grep -E 'VERI_GH_JSON|environ|Adapter\(' > /dev/null && [ "$(grep -c VERI_GH_JSON F)" -eq "$(awk '/^def _select/,/^$/' F | grep -c VERI_GH_JSON)" ]` ⟦criterion 3⟧
- [ ] Every public name (`NoAnswer`, `gh_rest_list`, `gh_list`, `gh_json`, `gh_issue_view`, `gh_issue_edit`, `gh_issue_create`) keeps its signature and return value: `tests/py/test_github.py` and its callers' suites pass, unmodified, in `make test` ⟦full-suite⟧ ⟦criterion 4⟧
