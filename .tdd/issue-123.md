# Plan for #123 — Walkthrough: since-mode skips every script newer than the chosen version — a whole new script is a stop, and the choice needs a control and a visible paint

- [x] the build emits each script's own `since` to the page (on the script's header, or as a map the client reads), and a tree with no version layer emits none and still builds
- [x] a script whose `since` ranks after the chosen version is a stop: its header is a mark lit for that reader, and `n`/`p` and the crumb-bar buttons reach it in page order before any hunk inside it; a script whose `since` is the chosen version or earlier is not a stop by its header
- [x] pressing `n` or clicking the crumb-bar next button in the page lands on a newer script's header before its first hunk: the script header carries a mark the stepper collects, ranked with the hunk marks in document order, and a script whose `since` is the chosen version or earlier carries none
- [x] the index row of the version a script arrived in lists it as `<script> · new` when that version ranks after the chosen one, and does not list it otherwise
- [x] choosing a version paints the answer in the DOM: every hunk mark, commentary chip and new-script header carries class `lit` or `dim` by the tag-order rule, the index rows `index(since)` does not return are hidden, and at rest nothing is dimmed or hidden
- [ ] the paint is visible: the page's stylesheet gives `.dim` marks a faded rendering and `.lit` marks a highlighted one, so a reader who chose a version sees which hunks, chips and new-script headers are news, while a mark with neither class renders exactly as before
- [ ] the capability index carries a version `<select>` (newest first plus a none option) wired to `choose(tag)` and a "mark read up to vX" button wired to `markRead()`, both found by visible text or accessible label; the select reflects `since()` at load and after `hashchange`, and changing it updates the paint without a reload
- [ ] `make docs` regenerates the page, and `make docs-check` and `make docs-test` pass
