### `tick-ledger.sh --already-holds <reason-file>` exits 1, leaving the ledger and `.tdd/events.jsonl` byte-identical (no events file created), when the reason file is empty or carries no `REASON:` line with non-blank text after the colon (a file holding only `REASON:` followed by blanks counts as none), pinned by one small case in `skills/tdd/scripts/tests/py/unit/test_tick_ledger_already_holds.py`; the existing case there in which a reason file holding `REASON: already holds; rerouted to pin step 4` retires the step with exit 0 keeps passing ⟦criterion 1⟧
- `tick_ledger.py` parses `REASON:` lines in two places (the new check at line 70 and the event reader at line 126). Sharing one helper would change behaviour when a file has several `REASON:` lines, because the event reader takes the first line even if it is blank. I left it alone.
