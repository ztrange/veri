The new module is `skills/tdd/scripts/veri/context_budget.py`, imported the way `parallel_conductors.py` already imports its siblings (`try: from context_budget import … except ImportError: from .context_budget import …`). Its function is pure: given the watch's state so far, the conductor's stream lines and the budget as an int, it returns the new state, each context reading (the sum of `cache_read_input_tokens` and `cache_creation_input_tokens` on an assistant line carrying both) and whether the budget is exceeded — the check armed by an assistant line carrying `event.sh step-done` and made on the next line carrying `"type":"user"`, which disarms it. It does no I/O, reads no environment and signals nothing; printing `context <n> <tokens>`, reading `VERI_CONDUCTOR_CTX_BUDGET`, orchestrate.py's stop on a line with no trailing newline, and the action on a breach (orchestrate.py returns from `_watch`; parallel_conductors.py sends SIGTERM to the supervisor and ignores every later line) stay in the callers. The two copies differ on one input: after arming, a line carrying both `"type":"user"` and `"type":"assistant"` falls through to the assistant handling in orchestrate.py and is skipped by parallel_conductors.py's `continue`; stream-json escapes quotes inside strings, so no line the conductor writes carries both markers unescaped, and the shared function takes parallel_conductors.py's `continue`.
