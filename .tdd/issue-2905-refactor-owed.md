- test-only | extract the shared stub-script and red-file setup in the two process cases into a helper
### `rerun-alone.sh '<alone-cmd>' <red-output-file>` exits 0 when every test file the red output names passes when run alone through the alone command, and writes one `suite-flake` event to the run's event log naming each such file; pinned by a process case in `skills/tdd/scripts/tests/py/test_rerun_alone_process.py` with a stub alone command that passes for every named file ⟦criterion 1⟧
- test-only | extract a shared helper for the repeated alone-stub and red-output file setup in test_rerun_alone_process.py
