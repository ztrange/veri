### Given a pairs table with one row naming an old bash case, a kept bash case of the same suite it is redundant with, and a mutation patch to a production file, the pairs check (`mutation-parity.sh <pairs-table>`) applies the mutation, runs both cases, and — when the old case goes red, another case of its suite stays green and the kept case goes red — prints a report row naming the old case, the kept case, the mutation and the result `proven`, and exits 0 ⟦criterion 1⟧
- test-only | in `mutation-parity.test.sh`, the first case builds its patch and pairs table with the same `sed` → `diff -u` → `printf` sequence that `not_proven` repeats. Both could share one helper that takes a name and a sed expression and returns the patch and table paths. Only a file under `tests/` would change, so it was not applied here.
### A row whose valid mutation leaves its kept case green is reported `unproven`, the report naming that kept case, and the pairs check exits 1 ⟦criterion 1⟧
- test-only | in `skills/tdd/scripts/tests/mutation-parity.test.sh`, the kept-stays-green case repeats the steps `not_proven` already does: sed the mutation, `diff -u` it into a patch, write the one-row table, run `$PARITY`. The first proven case repeats the same steps too. One helper that builds the patch and table and runs the check would remove all three copies.
### A row whose mutation leaves its old case green is reported `owed` (the mutation is not valid), and the pairs check exits 1 ⟦criterion 1⟧
- test-only | extract the repeated sed/diff/printf patch-and-table construction in mutation-parity.test.sh (proven case, not_proven helper, kept-stays-green case) into one helper that the cases share
### A row whose old case is replaced by a named pytest case (a node id) runs that pytest case under the mutation: proven when it goes red, unproven naming it when it stays green ⟦criterion 1⟧
- test-only | in `mutation-parity.test.sh`, the `replaced` helper repeats the steps that the kept-stays-green case and the two owed cases each write out inline: run `$PARITY` on a table, capture the exit code, then grep the output row for a case name and a result word. One helper shared by all four would remove the copies, but the change touches only files under `tests/`.
