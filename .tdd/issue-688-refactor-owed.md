- `pr_head` in `wait-ci.sh` prints Python's own spelling of `mergeable` (`True`/`False`/`None`), and the main loop matches the literal `False`. A clearer form: have the Python print a word of its own, e.g. `conflicting`, so the bash side doesn't depend on how Python spells a boolean. It isn't duplication removal, so I left it alone.
