# Plan for #959 — detach-command.sh runs as a Python module behind its sh shim, as veri/detach_command.py

Note for every reader of this plan: since the issue was written, #964 (closed; commit 2e5b6ce7f on main) changed `wait`: a max-seconds that is not all ASCII digits is refused with exit 2 and the usage line before any file is read, pinned by the two #964 cases in tests/detach-command.test.sh. So the spec's `1.5` never-times-out, `abc` exits 1 and `10+5`-is-15 quirks no longer exist on main; porting with no behaviour change (the spec's own rule) means pinning the refusal, and only the leading-zero octal reading of an all-digits max-seconds survives as a quirk.
