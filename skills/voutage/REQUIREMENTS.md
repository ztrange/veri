| ID | Requirement | Why |
|---|---|---|
| VO1 | The skill says near its top that it obeys `operator/PRINCIPLES.md` under the veri clone root and to read it first; defines `$S` as `skills/tdd/scripts/`, reached from this skill's base directory as `../tdd/scripts/`; and says every command runs from the target repository's main working tree and every `.tdd/` path is under it. | An operator skill's shape, as `vmerge`'s (PRD 033, VO1; D4). |
| VO2 | On a failed merge it runs `$S/github-outage.sh enter <pr-url>`, which reads GitHub's status page in-process with `github-status.sh`'s default components (the ones a merge needs); on a counting incident the script writes `.tdd/github-outage` holding the status lines followed by the failed PR's url on a line of its own (`entered`), and the skill tells the human (the coordinator, when one is attached) in one line that local mode has begun and why, naming the incident. | Local work is authorized only by the status page; the file is the mode, re-read, never remembered (PRD 033, VO3; D1, P1). |
| VO3 | On `enter`'s exit 1 (GitHub answered, nothing counts) no file is written and the skill reports the failed merge in one line as an unexplained merge failure, with the `young` lines the script printed, if any. | No counting incident, no authorization (PRD 033, VO4; D1). |
| VO4 | On `enter`'s exit 2 the mode is left as it is (an existing `.tdd/github-outage` stays, none is created): when it printed `no answer from GitHub's status page`, the skill tells the human in one line that the status page gave no answer; when it printed `not a PR url`, it reports that once, in one line, naming the url. | No answer is not "up", nor "down" (PRD 033, VO5; D3). |
| VO5 | While `.tdd/github-outage` exists the session starts no merge: a ✅ Done run whose review is OK is not merged; `$S/github-outage.sh hold <pr-url>` appends its PR url to the file on a line of its own, in the order the runs ended. The file's PR urls, the failed PR's first, are the merge order. | Held, in order; nothing merges locally until PRD 033.2 (PRD 033, VO6; C5). |
| VO6 | While the file exists exactly one detached `github-status.sh wait 3600` runs per main working tree, started by `$S/github-outage.sh wait-start` and waited on by a background `$S/github-outage.sh wait`; it is started again when it ends with code 3; when it ends with code 2 the session tells the human in one line that no read got an answer, and with any other code in one line naming the code, and starts it again. A session that starts, recovers or resumes with the file present runs no one-shot check: it tells the human once of the PRs another live process holds in the merging list (`status --pid` prints them `live`), and it waits on that wait when it is live and starts it when it is not. | Leaving local mode is a blocking wait (P3); a reset must not lose it (PRD 033, VO7; C4). |
| VO7 | When the wait ends with code 0 the session merges the PRs the file lists, in the file's order, each through `vmerge` as a ✅ Done run is merged, claiming each with `$S/github-outage.sh take` before its merge starts and settling it once `vmerge` has reported; the script removes the file when nothing is left held or merging (`ended`), and the session then tells the human in one line that local mode has ended. | The held runs land in the order they finished (PRD 033, VO7; D3). |
| VO8 | The skill names no repository, issue, branch, label or person. | No project facts in a skill (PRD 033, VO8; P12). |
